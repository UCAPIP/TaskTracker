# Task Tracker CLI

Простое консольное приложение для управления списком задач. Позволяет добавлять, обновлять, удалять задачи, менять их статус и просматривать список с фильтрацией. Все данные хранятся в локальном файле `Tasks.json`.

Проект реализован на **Go** без использования внешних библиотек — только стандартная библиотека.

---

## ✨ Возможности

- ➕ Добавление задач
- ✏️ Обновление описания задачи
- 🗑 Удаление задачи
- 🔄 Смена статуса: `todo` → `in-progress` → `done`
- 📋 Просмотр всех задач
- 🔍 Фильтрация задач по статусу
- 💾 Автоматическое сохранение в `Tasks.json`
- 🕐 Автоматическое отслеживание времени создания и обновления

## 🚀 Установка и сборка

1. Склонируйте репозиторий:
```bash
git clone <адрес-репозитория>
cd task-tracker-cli
```

2. Соберите бинарный файл:
```bash
go build -o task-cli main.go
```

3. Запускайте команды через собранный файл:
```bash
./task-cli <command> [args]
```

> **Для Windows** используйте `task-cli.exe` вместо `./task-cli`.

Альтернативно можно запускать без сборки:
```bash
go run main.go <command> [args]
```

## 📖 Использование

### Добавить задачу

```bash
task-cli add "Купить продукты"
```

Описание с пробелами можно передавать как один аргумент в кавычках или как несколько аргументов — они будут объединены:

```bash
task-cli add "Купить продукты и приготовить ужин"
task-cli add Купить продукты и приготовить ужин
```

### Обновить описание задачи

```bash
task-cli update 1 "Купить продукты, приготовить ужин и помыть посуду"
```

### Удалить задачу

```bash
task-cli delete 1
```

### Пометить задачу как выполненную

```bash
task-cli mark-done 1
```

### Пометить задачу как в процессе

```bash
task-cli mark-in-progress 1
```

### Показать все задачи

```bash
task-cli list
```

### Показать задачи по статусу

```bash
task-cli list done         # только выполненные
task-cli list todo         # только запланированные
task-cli list in-progress  # только в процессе
```

## 🗂 Структура данных

Каждая задача хранится как объект со следующими полями:

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | `int` | Уникальный идентификатор задачи |
| `description` | `string` | Текст задачи |
| `status` | `string` | Статус: `todo`, `in-progress`, `done` |
| `createdAt` | `string` | Дата и время создания (`2006-01-02 15:04:05`) |
| `updatedAt` | `string` | Дата и время последнего обновления |

### Пример `Tasks.json`

```json
[
  {
    "id": 1,
    "description": "Изучить указатели в Go",
    "status": "done",
    "createdAt": "2026-09-18 10:00:00",
    "updatedAt": "2026-09-18 10:02:00"
  },
  {
    "id": 2,
    "description": "Написать README",
    "status": "todo",
    "createdAt": "2026-09-18 10:01:00",
    "updatedAt": "2026-09-18 10:01:00"
  }
]
```

---

## 🎯 Доступные статусы

| Статус | Значение | Описание |
|--------|----------|----------|
| `todo` | По умолчанию | Задача создана, но ещё не начата |
| `in-progress` | В процессе | Задача в работе |
| `done` | Выполнена | Задача завершена |

## ⚠️ Обработка ошибок

Программа корректно обрабатывает следующие ситуации:

- **Файл не существует** — при первом запуске создаётся автоматически.
- **Некорректный ID** — выводится сообщение об ошибке.
- **Задача не найдена** — выводится сообщение `Задача с id X не найдена`.
- **Неизвестная команда** — выводится список доступных команд.
- **Неизвестный фильтр** — выводится сообщение об ошибке.

Все ошибки пишутся в `stderr`, программа завершается с кодом `1`.

## 🛠 Технологии

- Язык: **Go**
- Хранение данных: **JSON-файл** (`Tasks.json`)
- Использованы только пакеты стандартной библиотеки:
  - `encoding/json` — сериализация/десериализация
  - `os` — работа с файлами и аргументами командной строки
  - `strconv` — конвертация строк в числа
  - `strings` — работа со строками
  - `time` — работа с датами
